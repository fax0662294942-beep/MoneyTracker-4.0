# 💰 MoneyTracker

App web per la gestione di spese, entrate e budget personali.

## 🚀 Caratteristiche

- ✅ **Account Multipli** - Gestisci account separati (Famiglia, Personale, ecc.)
- ✅ **Budget Mensili** - Imposta limiti di spesa per categoria
- ✅ **Statistiche Dettagliate** - Grafici e trend
- ✅ **Trasferimenti** - Sposta fondi tra account
- ✅ **Import CSV** - Importa da 1Money
- ✅ **Offline First** - Funziona senza connessione
- ✅ **PWA** - Installabile come app

2. Incolla: https://fax0662294942-beep.github.io/MoneyTracker-2.0/
3. Click "Package for Stores" → Android
4. Download APK

## 💾 Dati

Tutti i dati sono salvati **localmente** nel browser (localStorage).
- Privati e sicuri
- Nessun server
- Export/Import disponibile
